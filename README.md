# 鳴潮：対決 リモート対戦アシスタント

DroidCamのカメラ映像から、クリックした位置にある「鳴潮：対決」のカードを認識し、
カード情報を表示するWindowsデスクトップアプリです。

現在は開発環境とカード画像アセットを準備している段階です。

## 必要環境

- Windows 10またはWindows 11
- Git
- [uv](https://docs.astral.sh/uv/)

Python本体と仮想環境はuvが管理するため、Pythonを別途インストールする必要はありません。

## 開発環境のセットアップ

PowerShellでリポジトリのルートを開き、uvを導入します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://astral.sh/uv/0.12.19/install.ps1 | iex"
```

PowerShellを開き直した後、依存関係を同期します。

```powershell
uv sync --all-groups
```

## 開発用コマンド

```powershell
# テスト
uv run pytest

# 静的解析
uv run ruff check .
uv run mypy

# フォーマット確認
uv run ruff format --check .
```

## プロトタイプの起動

先にAndroid側とWindows側でDroidCamを起動し、仮想カメラを利用できる状態にします。
その後、リポジトリのルートで次を実行します。

```powershell
uv run wuwatcg-assistant
```

起動後の操作は次のとおりです。

1. Windowsから取得したカメラ名の一覧で、`DroidCam Video`など使用する機器を選び、
   `カメラ開始`を押します。OBSを使う場合は`OBS Virtual Camera`を選択します。
2. 画面下部に`準備完了`と表示されるまで待ちます。現在の環境では198画像の準備に約9秒かかります。
3. 映像内で、調べたいカードの見えている絵柄部分をクリックします。周囲のカードと
   区別しにくい場合は、対象を囲むように左ドラッグして解析範囲を指定します。
4. 右側にカード画像と候補ドロップダウンが表示されます。候補から正しいカードを選べます。
   映像と認識結果の境界を左右にドラッグすると、右ペインの幅とカード画像の表示サイズを
   変更できます。
5. 右下のライフカウンターで自分のライフを管理できます。初期値は20です。
   値の左右にある`<`と`>`で1ずつ増減でき、リセットと表示・非表示の切り替えもできます。
6. ライフカウンター下のターン管理で、レベルアップ・切り替え・チャージの使用状況を
   アイコンで記録できます。回転矢印で3項目だけを一括リセットできます。
   ライフカウンター右の戦況カードでは、優勢／劣勢を色付きのトレンドアイコンで
   個別に切り替えます。

UIのアイコンには[Lucide](https://lucide.dev/)を使用しています。

ドラッグ中と認識処理中の黄色い破線が解析対象範囲、初期設定で水色の線が認識されたカード全体の
推定位置です。ドラッグ解析では黄色い範囲内の特徴点だけを照合に使用しますが、認識完了後は
黄色い範囲と赤いクリック位置が消え、認識枠だけが残ります。認識枠は隠れている部分を
含むカード全体の推定位置を表示します。

画面左上の設定アイコンから「認識枠の色…」を選ぶと、認識されたカード全体を示す線を
任意の色へ変更できます。

同じ設定メニューの「言語」から、日本語・English・简体中文へ表示を切り替えられます。
ルール用語は公式総合ルールに合わせ、次のように対応付けています。

| 日本語 | English | 简体中文 |
| --- | --- | --- |
| ライフ | Life | 生命值 |
| レベルアップ | Level Up | 升级 |
| 切り替え | Switch | 切换 |
| チャージ | Charge | 充能 |
| 優勢 | Advantage | 优势 |
| 劣勢 | Disadvantage | 劣势 |

日本語と簡体中国語は公式サイト掲載の総合ルールに準拠しています。公式サイトには英語版
ルールがないため、英語は同じルール定義に対応する表現です。

一覧の表示名はWindowsが提供する名前です。内部では各カメラ固有のデバイスIDを保持し、
選択されたデバイスを直接開きます。接続・切断によるWindowsのカメラ一覧変更も自動的に
反映されます。

解像度やフレームレートは固定値にせず、選択したカメラがWindowsへ公開している形式から
最大画素数のものを使用します。同じ解像度の形式が複数ある場合は、最大フレームレートが
高いものを選択します。実際に使用中の解像度とフレームレートは画面下部の状態欄に表示されます。

カード同士が重なっている場合も、カードの四辺ではなく可視部分の特徴点を使って照合します。
ただし、固有の絵柄がほとんど隠れているカードや、強い反射・激しい手ぶれがある映像は
認識できない場合があります。

## カード画像

カード画像と索引は `assets/cards` に格納されています。取得元と再取得方法は
`assets/cards/README.md` を参照してください。
