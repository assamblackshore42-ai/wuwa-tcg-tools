# 鳴潮：対決 カード画像

公式サイトの公開カード一覧APIから取得した日本語版カード画像です。

- 公式カード一覧: https://wwcg.ucp-jp.com/jp/card
- 画像形式: WebP
- 画像件数: 198件
- `cards.csv`: カード番号、名称、ローカルファイル名、公式画像URLの索引
- `metadata.json`: 取得日時、取得結果、全レコードのJSON索引

同じカード番号・名称に異なるレアリティの画像が複数ある場合、2件目以降のファイル名には公式APIのIDを付けています。

再取得するには、リポジトリのルートで次を実行します。

```powershell
pwsh -NoProfile -File .\scripts\download-card-images.ps1
```

既存ファイルも上書きする場合は `-Force` を付けます。

カード画像・名称などの権利は各権利者に帰属します。利用・再配布時は公式サイトの規約と権利者の条件を確認してください。
